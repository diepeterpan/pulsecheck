Quick Import Guide

  • 1
    One Hostname Per Line
    Use bare service names, hostnames, or IP addresses. Protocol prefixes (http://, https://) are automatically stripped.
  • 2
    Automatic Port Discovery & Port Settings
    PulseCheck automatically probes each new service across standard ports (80, 443, 8080, 8443, etc.) to detect active ports. Probing verification (Match string and URL path) is configured individually per port rather than at the service level; newly discovered ports default to the service hostname token and root path (/).
  • 3
    Duplicate Protection
    Services already registered in the system are skipped without modifying their existing configuration or port checks.
  • 4
    Background Execution
    Imports run asynchronously in a worker pool. You can monitor progress live or safely cancel anytime.

Supported Columns

Column Type Description
Service Required Service name, hostname, or IP
Match Optional Per-port token(s). A single string applied to all non-ICMP ports, or a comma-separated list positionally aligned with each port in Ports (e.g. "welcome, api"). ICMP ports ignore match tokens. Leave blank for none.
URL path Optional Per-port HTTP path(s). A single path applied to all non-ICMP ports, or a comma-separated list positionally aligned with each port in Ports (e.g. "/, /health"). ICMP ports ignore URL paths. Leave blank for default (/).
Comment Optional Description or notes
Paused Optional 0 = Active, 1 = Paused
Proxy Optional 1 = Proxy, 0 = Direct
Protocol Optional Single protocol (e.g. https) applied to all ports, or a comma-separated list matching each port position (e.g. "http, https, icmp-ping"). Leave blank for auto-detect. Options: http, https, socket, udp, udp-ssl, icmp-ping
Ports Optional Monitored ports e.g. "80, 443". ICMP ping is portless and specified as icmp (e.g. "80, 443, icmp" or "icmp").

Export Structure & Preview

The exported CSV file is structured with per-port Match strings, URL paths, and protocols positionally aligned with the Ports column:

Service,Match,URL path,Comment,Paused,Proxy,Protocol,Ports internal.corp.local,"welcome, api","/, /health",Gateway,0,1,"http, https","80, 443" api.example.com,api,,Production API,0,0,http,"443, 8443" edge-router.local,,,Edge Router,0,0,icmp-ping,icmp hybrid-node.example,"ok, , ","/ping, , ",Multi Probe,0,0,"http, https, icmp-ping","80, 443, icmp"

Per-Port Configuration: Match tokens and URL paths are configured per individual port. When all non-ICMP ports share the same value (or only one port exists), a single value is exported. When ports differ, a comma-separated list aligned 1-to-1 with the non-ICMP ports in Ports is exported. ICMP ping probes are portless and never have match tokens or URL paths.
