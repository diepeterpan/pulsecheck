Proxy Architecture & Usage

1. HTTP Forward Proxying Standard HTTP requests are transmitted using absolute request URIs (e.g. GET http://target/health) with host and proxy credentials.
2. HTTPS CONNECT Tunneling For secure endpoints, PulseCheck issues an HTTP CONNECT command to establish a bidirectional tunnel before starting the TLS handshake.
3. TCP Probe Protection Direct raw TCP fallbacks are automatically disabled for proxied services to ensure traffic never bypasses your corporate proxy.
4. Service Activation Enable the "Use Proxy Server" checkbox when adding or editing services. A blue Proxy badge will appear on Status and Services pages.
